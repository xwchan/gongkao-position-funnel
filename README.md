# 2027 国考岗位筛选器

专注《中央机关及其直属机构2027年度考试录用公务员招考简章》的岗位筛选。个人学习项目，保持 GitHub public，并通过 GitHub Pages 免费在线使用。

把岗位筛选过程变成可交互的漏斗：每加一层限制，立即看到还剩多少**岗位 / 招录名额**、这一层筛掉多少，以及剩余岗位的原文备注。无需注册、无需安装、无需导入表格。

**[点这里直接使用在线版](https://xwchan.github.io/gongkao-position-funnel/)** · **[下载单文件 HTML，离线使用](https://github.com/xwchan/gongkao-position-funnel/releases/latest/download/index.html)**

> 非官方的个人学习工具，不构成报考建议或资格证明。数据源网站为[国家公务员局考录专题网站 · 相关下载](http://bm.scs.gov.cn/pp/gkweb/core/web/ui/business/download/gkdownloads.html)，文件提供者确认数据文件下载自该网站。我们核对了本地源文件与网页的岗位内容；但没有另行从官方网站下载一份并校验哈希，因此**不能独立证明发布版本与官网完全一致**。请以正式公告及招录机关解释为准。

**原始数据下载：[ZIP](https://xwchan.github.io/gongkao-position-funnel/data/gk2027-original.zip) · [XLS](https://xwchan.github.io/gongkao-position-funnel/data/gk2027-original.xls)**（需要联网）

## 怎么用

1. 打开上方在线版链接，或者下载 `index.html` 后双击打开（离线也能用）。页面上方明确显示 `原始岗位 = 已筛除岗位 + 剩余岗位`。
2. 左侧启用或关闭条件、选择你的学历/应届身份/省份等。上下箭头可调整过滤顺序；**顺序影响每层新增筛除数量，但不影响最终交集**。
3. 点“查看”阅读岗位的专业要求及**原表备注**；确定要自己进一步核实的岗位后，导出当前筛选结果的 CSV。

数据和界面都在仓库根目录的**一个 `index.html` 文件**里：19,426 个岗位、35,691 个招录名额，约 14 MB。浏览器直接运行，不依赖网络 API 或额外文件。浏览器会在本机记住筛选条件；重新打开时可点击“查看全部岗位”关闭筛选，恢复全量。

## 数据来源与使用边界

- **岗位数已验证**：4 个有效工作表岗位分别为 99、312、18,193、822，合计 19,426 个；页面默认演示过滤掉 19,326 个，剩 100 个，绝非只有 19,326 个。我们对页面的 19,426 行逐字段对照本地 Excel，共核对 369,094 个源字段，全部一致。详细方法和边界见 [VALIDATION.md](VALIDATION.md)。
- 输入文件名：`中央机关及其直属机构2027年度考试录用公务员招考简章.xls`。原始 ZIP 内 XLS 的 SHA-256：`6b3da70baabe31a4a202c6b1179040db7003a956bc85c79cd35e3fb739d9520a`。这是**文件一致性标识**，不是官方真实性证明。仓库 `data/` 中提供原始 ZIP 和从中原样提取的 XLS，均未修改文件内容；详见 [原始数据说明](data/README.md)。
- 岗位信息来自用户确认从官方网站下载的文件。源码使用 MIT 许可证；**不以该许可证重新授权招考简章/岗位数据**。数据署名与再使用风险见 [DATA_NOTICE.md](DATA_NOTICE.md)。
- 每行计一个岗位，用部门代码 + 职位代码校验唯一性；名额取“招考人数”。“单独看每项”以原始岗位池独立计算；左侧漏斗按当前顺序累计计算。
- 学历、政治面貌、基层年限和服务基层项目匹配结构化字段；专业仅按文字包含匹配，不理解专业代码/类别或相近专业。学位与最高学历、附加资格都需人工核对。
- **应届身份不是单独字段**：程序保守识别备注里明确的“仅限/限 2027 届”或“限应届”等表述。未明确限制的岗位暂时保留给不同身份，但不等于确认可报考。只有“非应届毕业生须有工作经历”之类的句子不是专招非应届岗位，也不会直接排除非应届生。一般应届认定以招录机关解释为准。
- 备注中还可能限制年龄、性别、户籍、英语成绩、证书、专业方向或特定工作经历。**筛出来的岗位不等于符合报考资格**；此工具不显示竞争比和报名人数。
- 明细搜索只影响当前明细列表，不影响漏斗统计与 CSV 导出；CSV 是当前漏斗所有剩余岗位。

## 开发者：重新生成 / 复用工具

Python 3.9+，可从本地 `.xls` 或包含单份 `.xls` 的原始 `.zip` 重建单页（不会上传输入文件）：

```bash
python3 -m pip install -r requirements.txt
python3 build.py --input '/本地路径/招考简章.zip' --output index.html
```

输入应具有 2027 年招考简章的结构（第 2 行是表头）。结构不符、招考人数无效或职位标识重复时直接报错。可用 `python3 verify.py --input '/本地路径/招考简章.zip' --html index.html` 逐字段审计生成结果。核验结论见 [VALIDATION.md](VALIDATION.md)。想先体验完全**虚构的样例数据**，可运行 `python3 build.py --demo`，打开 `dist/demo.html`。

测试：`python3 -m unittest discover -s tests -v`。修改分类口径或 UI 后请更新测试，并检查手机端布局。代码在 `src/`；公开可用的最终单文件是根目录的 `index.html`。
