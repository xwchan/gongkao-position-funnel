# 国考岗位数据漏斗

一个**本地生成、离线运行**的国考岗位筛选玩具。把多层条件的筛除数量、岗位数及招录名额画成漏斗；可调整层级顺序、查看岗位原文、按当前筛选导出 CSV。改变顺序会改变每层的边际筛除量，但不会改变最终交集。

> **非官方工具，不构成报考资格判断。** 岗位数据由使用者自行提供。本仓库只开源程序和虚构演示数据，**不包含招考简章、真实岗位明细或生成后的真实数据网页**。MIT 许可仅覆盖本仓库代码、文档和虚构演示数据，不授予外部招考数据的再分发权。请以招录机关的正式公告和解释为准。

## 开始使用

需要 Python 3.9+。单页产物无 CDN、无账号、无后端；生成时不会上传招考文件。

```bash
python3 -m pip install -r requirements.txt
python3 build.py --input "/本机路径/中央机关及其直属机构2027年度考试录用公务员招考简章.xls"
```

打开生成的 `dist/index.html`。也可指定 `--output /绝对路径/岗位数据漏斗.html`。输入格式为该年度招考简章的 `.xls` 原版结构：第 2 行是表头、第 3 行起是岗位。表头不匹配会直接报错，避免无提示地错读其他表格。

没有本地数据时，可体验**完全虚构**的示例：

```bash
python3 build.py --demo
```

打开 `dist/demo.html`。示例机关、代码及岗位都是虚构的；不要用于报考。

## 当前规则和限制

- “岗位数”按表中一行一个职位；使用“部门代码 + 职位代码”校验唯一性；“名额”是“招考人数”求和。左侧各层按当前顺序计算；“单独看每项”以全量为基准，不是累计漏斗。
- 学历、政治面貌、基层年限、服务基层项目直接匹配表格相应字段；工作省份从工作地点提取；专业仅按原文**字面包含**。学位、学历、专业目录的对应关系及最高学历限制尚不能自动验证。
- “应届生身份”**不是原表的独立列**：仅识别备注中明确的“限/仅限/招录对象为 2027 届或应届毕业生”等字样；普通的“非应届须有工作经历”是附加条件，**不等于只招非应届**。未识别明确限制时，三类身份均暂时保留，并提示核对备注。“其他应届身份”的具体认定由招录机关解释。
- 岗位备注仍可能有限定年龄、性别、户籍、英语成绩、资格证书或特定工作经历等要求。未自动过滤不代表有资格报考。
- 搜索只查当前结果明细，不影响漏斗和 CSV 导出；CSV 含当前漏斗全部剩余岗位。筛选设置自动保存在该浏览器的本地存储中，按输入数据文件名/修改时间隔离。
- `build.py` 不核验下载文件的真伪或发布主体；输入文件须由使用者核实。**代码许可不覆盖外部招考材料。**

## 测试

```bash
python3 -m unittest discover -s tests -v
```

测试覆盖应届分类正反例、虚构样例生成和岗位标识校验；CI 会在推送后运行相同测试并生成虚构演示页。需要进一步用浏览器测试时，可用本地 HTML 文件检查切换条件、导出和手机端布局。

## 项目结构

- `build.py`：读取本地 `.xls` 并嵌入到独立 HTML；也支持虚构演示。
- `src/index.html`：无外部依赖的交互页面模板。
- `src/classify.py`：备注的保守应届文字分类。
- `tests/`：规则和产物回归测试。
